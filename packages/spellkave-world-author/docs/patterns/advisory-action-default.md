# Advisory Action Default

Use public `ui.affordance_defaults` metadata on one `affordance_template` to
publish a bounded draft suggestion to clients. It is presentation data: it
never makes an action eligible, supplies reducer arguments, or replaces an
ADR-0142 prompt occurrence.

```toml
[[metadata_attachments]]
target_kind = "affordance_template"
target_ref = "srd/dodge/affordance"
namespace = "ui.affordance_defaults"
payload_json = '{"version":1,"target":{"kind":"actor"}}'
bundle_id = "srd"
source = "manifest"

[[metadata_namespaces]]
audience = "public"          # the SDK reader drops non-public rows
bundle_id = "srd"
namespace = "ui.affordance_defaults"
```

Copied from `packages/spellkave-srd-cc/fixtures/ui/affordance-defaults.toml`
(generated by `src/ui/affordance-defaults.ts`); reader:
`packages/spellkave-sdk/src/core/readers/affordance_defaults.ts`.

The payload has `version: 1` and may contain one `target` plus
`input_values`. `target.kind = "actor"` means the caller's own disclosed body;
`reference` requires an exact `target_ref` that remains visible to that caller.
Input values must match the same template's `ui.affordance_input` schema and
are scalar strings or numbers. Do not publish utterances, semantic context,
occurrence ids, or values inferred from a place, a current speaker, or an
action label.

One template owns one whole default. A client withholds duplicate or malformed
attachments rather than choosing precedence. A player can always override a
suggestion with an explicit bound target or typed input. Prompt responses are
not meant to consume ordinary defaults; their source and response contract
remain authoritative (design intent; no test asserts this yet).
