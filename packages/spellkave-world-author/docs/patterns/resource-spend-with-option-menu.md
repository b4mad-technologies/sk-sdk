# Resource spend with option menu

## Name

`resource-spend-with-option-menu` — Resource spend with option menu

## Problem

I have a shared pool (spell slots, Channel Divinity uses) and several effects that each spend one use — how do I author the pool once and branch the menu?

## Forces

- One resource_definitions row is the pool; many actions debit it.
- Option menus for CD effects may be partial (one live branch, others backlog).
- Gate on `actor.stat(pool) >= 1` on the affordance and debit on success.
  No validator enforces the gate; without it a debit at 0 is a floored no-op
  and the effect still lands
  ([modify-resource-floored-noop](../repairs/modify-resource-floored-noop.md)).

## Solution

Author the pool (`spellkave_define_resource` / chapter unit). Each option is its
own action/affordance with the same spend debit (`ModifyResource` delta `-1` on
the pool) and distinct effect body. Advancement/metadata may list members for
DM dialogue; live spend is still per-action. See
[`spellcasting-substrate.md`](../../../spellkave-srd-cc/docs/spellcasting-substrate.md)
and [`caster-features-l1-4.md`](../../../spellkave-srd-cc/docs/caster-features-l1-4.md).

## TOML example

Copied from `packages/spellkave-srd-cc/fixtures/base/spells/casting.toml + per-spell debit in fixtures/base/spells/level-1/* (generated by spell-slots.ts / spell-behaviors.ts); Channel Divinity uses in caster-features`:

```toml
[[resource_definitions]]
bundle_id = "srd"
display_name = "Level 1 Spell Slot"      # required
initial_value = 0
max_value = 9
min_value = 0
recovery_rule = "long_rest"
resource_definition_id = "srd/spell_slot_1"
value_kind = "int"                        # required

# each leveled cast gates + debits the same pool:
# predicate_source = "actor.stat('srd/spell_slot_1') >= 1"
# frame_write ModifyResource { resource = "srd/spell_slot_1", delta_source = "-1" }
```

## Known misuse / anti-pattern

One action that tries to encode every CD option with free-text parsing. Separate pools per option that never share recovery. Expecting a single action with a free-form integer parameter for Lay On Hands / Font costs — discrete menu rungs are the expressible shape until a parameterised spend leaf exists.

## SRD features that use this

- **Spell slots** (shared srd/spell_slot_1..2).
- **Channel Divinity** uses — Cleric Divine Spark heal/damage, Turn Undead,
  Preserve Life; Paladin spend stub (L12c).
- **Lay On Hands** discrete 1/5/10 HP menu (L12c).
- **Font of Magic** slot↔sorcery-point conversions (L12c).
- Single-option pools (Bardic Inspiration, Wild Shape uses) use the same
  gate + debit without a menu.
