# Lingering hazard zone (self-pulsing)

## Name

`lingering-hazard-zone` — Lingering hazard zone (self-pulsing)

## Problem

I need a Cloudkill / burning-room hazard that damages whoever stands in it each round, then fades, without the player re-casting every turn.

## Forces

- The world clock must not kill actors without a subject (ADR-0004 / ADR-0041).
- Pulses need caster (or fire-entity) attribution and a bounded `repeats_remaining`.
- Cast-time Inscribe of a spatial marker is separate from the pulse body (autonomy fence).

## Solution

Author a subject-bound `[[autonomy_jobs]]` (or cast → `ScheduleAutonomyJob`) whose
`dsl_function` is a consequence that fans `ForEachActorInRadius` → `ModifyResource`.
Full guide: [`lingering-hazard-zones.md`](../lingering-hazard-zones.md). Live
no-cast proof: `mech_burning_room`.

## TOML example

Copied from `packages/spellkave-mechanics/fixtures/mech_burning_room/manifest.toml (generated by packages/spellkave-mechanics/src/burning-room.ts)`:

```toml
[[autonomy_jobs]]
anchor_place_node_id = "mech_burning_room/room"
bundle_id = "mech_burning_room"
dsl_function = "mech_burning_room/pulse"
frequency_ms = 6000
job_id = "mech_burning_room/fire_pulse"
repeats_remaining = 3
requires_subject_alive = false
subject_entity_key = "mech_burning_room/fire"

[[consequence_frame_writes]]
ordinal = 0
template_id = "mech_burning_room/pulse"
frame_write = { ForEachActorInRadius = { center_ref = "TargetSpatialRef", shape_id = "core/area/node_ball", shape_params_json = '{"ball_radius": 0}', predicate_source = "", body = [ { ModifyResource = { actor = "Actor", resource = "mech_burning_room/hp", delta_source = "-3" } } ] } }
```

## Known misuse / anti-pattern

Ambient world-clock damage with no subject. Unbounded `repeats_remaining`. Putting Inscribe on the pulse instead of the cast.
Calling `macro()` in the pulse's `ForEachActorInRadius.predicate_source`:
offline validation accepts it, but the kernel parses that predicate without
the macro table and disables the job at its first fire with
`MF-DSL-MACRO-UNKNOWN` (sk-jay0.2.43). Inline the macro body instead.

## SRD features that use this

- **Moonbeam / Flaming Sphere / Spike Growth** (srd-cc L12d `lingering_damage_zone`).
- **Cloudkill**: only the retired `srd` bundle authored its pulse (cast shape
  in lingering-hazard-zones.md); the srd-cc Cloudkill is identity-only.
- Generic **burning room** environmental hazard (mech_burning_room).
- **Caltrops / Ball Bearings** (srd-cc `srd/item/caltrops/spread`,
  `srd/item/ball-bearings/spill`, sk-jay0.3.19.6): a self-only Utilize verb
  spends the item, spares the creatures already on the node until their next
  turn start, and schedules a 10-round pulse on the user's node. The pulse
  predicate skips spared creatures and runs the occupant's Dexterity save; the
  body is damage plus a Speed 0 condition, or Prone, plus a "struck" status
  that spares the creature until its next turn start. Monster Death and PC
  Unconscious carriers follow in the same template. The pulse hits creatures
  standing in the area, not creatures that enter it: see
  `packages/spellkave-srd-cc/docs/equipment-catalogue.md` § Area hazards.
